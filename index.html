Tu guía de Programación Lineal

¡Hola! Soy Geo, tu guía

Te acompaño a plantear el modelo y elegir cómo resolverlo. Sigue estos pasos para obtener una solución explicada.

  1. 1
    Escribe la función objetivo

    Ingresa solo los términos, por ejemplo 3x + 2y. Elige si quieres maximizar o minimizar. Se aceptan fracciones como 1/2x + 3y.

  2. 2
    Añade las restricciones

    Escribe una por una y pulsa Añadir restricción. Incluye el operador y el límite, por ejemplo x + y <= 4 o 2x + y >= 6.

  3. 3
    Configura variables y método

    Define el signo de cada variable. El método gráfico requiere exactamente dos variables; para los demás modelos puedes usar Símplex, Símplex revisado, Gran M o Dos Fases según las restricciones.

  4. 4
    Opcional: trabaja con el dual

    Activa Trabajar el modelo dual y elige si resolver el primal o el dual. Al final se muestran ambos resultados y se comparan los valores de Z y W.

  5. 5
    Resuelve y revisa

    Pulsa el botón de cálculo. Verás el procedimiento paso a paso, las tablas exactas en fracciones, la aproximación decimal y la gráfica cuando corresponda.

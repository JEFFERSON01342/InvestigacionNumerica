# GeoMath

Para usar la gráfica de Desmos, no abras los archivos HTML con doble clic (`file://`).
Desde esta carpeta ejecuta:

```powershell
node server-local.js
```

Después abre [http://localhost:8080/](http://localhost:8080/); la página principal abre directamente Programación Lineal.

La página incluye Símplex estándar y revisado, Gran M, Dos Fases y método gráfico. El Símplex revisado muestra las matrices de cada iteración y también puede resolver el modelo dual.
